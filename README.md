# FN Asset Path Finder — complete GitHub Pages website

This package contains the complete website and both current Fortnite asset lists.

## Upload from a phone
1. Create a public repository on GitHub.
2. Extract this ZIP.
3. Upload every extracted file and folder to the repository. Keep `.github/workflows` and `.well-known` unchanged.
4. Open **Settings → Pages** and choose **GitHub Actions** as the source.
5. Push to the `main` branch. The Deploy to GitHub Pages action publishes the site.

`index.html` is the website. `website-in-one-yml.yml` also contains the full page and can publish it manually from the Actions tab.
